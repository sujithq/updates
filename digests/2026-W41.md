# Weekly Digest: September 28 – October 05, 2026

## Executive summary

This week’s news was dominated by platform readiness for AI-native development: GitHub expanded Copilot and security workflows, Microsoft Foundry added faster evaluation, retrieval, voice, and agent deployment capabilities, and Azure introduced more building blocks for agent apps and observability. On the infrastructure side, Azure shipped notable capacity and resilience updates, including Intel TDX confidential VMs, Lasv5/Laosv5 VM availability, regional resiliency for Azure Virtual Desktop, and broader networking support for distributed AI. Developers also got a steady stream of tooling updates across VS Code, Visual Studio, Aspire, Azure Developer CLI, .NET, and Azure DevOps. Finally, Azure Updates was heavy on lifecycle planning, with multiple VM retirements, SQL monitoring previews, AKS Ubuntu 26.04 preview, and several database and SQL platform enhancements.
