# Weekly Digest: Azure, GitHub, and Developer News  
**October 12 – October 19, 2026**

## Executive summary

This week’s news centered on practical AI adoption, with GitHub, Microsoft Foundry, and Azure all shipping features that make agentic development, code remediation, and grounded enterprise AI more usable in day-to-day workflows. GitHub’s biggest themes were software supply chain governance and AI-assisted security, including GA for open source license compliance, AI Scan for pull requests, and agentic autofix for code scanning alerts. On Azure, infrastructure and platform updates emphasized resilience and operational scale, highlighted by automatic zone balance for Virtual Machine Scale Sets, Azure Container Apps Sandboxes GA, and continued investment in Azure SRE Agent workflows. Developer tooling also stayed busy, with VS Code releases, .NET 11 RC2, Azure MCP Server 3.0, and new guidance on grounding and decision routing for AI agents.

## GitHub

GitHub’s updates focused on secure software delivery, AI-native development workflows, and enterprise administration. The most notable items were broad availability for compliance and security features, plus changes to Copilot models, notifications, and Actions governance.

- Open source license compliance reached general availability.
- AI Scan for pull requests is now generally available.
- Agentic autofix for code scanning alerts is now generally available.

- GitHub also published deeper technical reads on ambient intelligence, secret detection, repo hygiene automation, and Copilot onboarding.
