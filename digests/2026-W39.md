# Weekly Digest: September 14–21, 2026

## Executive summary

This week’s announcements centered on three big themes: more capable and governable AI agents, tighter developer workflows around GitHub Copilot and VS Code, and steady Azure platform expansion across app hosting, data, and infrastructure. GitHub focused on safer automation, stronger Actions protections, Copilot lifecycle updates, and better visibility into adoption and usage. On Azure, Microsoft continued to push Foundry, agent tooling, and MCP integrations while also shipping meaningful platform updates in PostgreSQL, networking, SAP infrastructure, and Application Gateway. For architects, the signal is clear: agent-based development is moving from experimentation into operationalization, with more emphasis on security, observability, policy, and production controls.

## GitHub

GitHub’s updates this week improved Copilot workflows, repository governance, authentication automation, and Actions security. The most important changes are around safer automation, runtime and model transitions, and better telemetry for teams managing Copilot at scale.

- Copilot code review introduced an improved review experience.
- GitHub Copilot weekly releases for September 14 rolled up the latest feature changes.
- GitHub announced selected Copilot models will be deprecated in mid-October.
- Copilot impact dashboard now includes feature engagement visibility.
- Agentic CLI customizations are now exposed through the usage metrics API.
- Workflow execution protections in GitHub Actions reached general availability.
- Stage-only npm tokens aim to make automation safer.
- Classic PAT and SSH key SSO authorization can now be automated.
- Code coverage ruleset conditions can now be managed through the REST API.
- GitHub detailed its Copilot runtime migration to Rust, using Copilot itself.

## Data & AI

Azure’s Data & AI news leaned heavily into agents, multimodal development, schema reliability, and local or enterprise AI deployment patterns. Foundry and Cosmos DB both gained tools that help teams move from prototypes to repeatable, spec-driven, production-oriented AI systems.

- Azure Cosmos DB added Spec-Driven Development support via a GitHub Spec Kit database extension.
- Microsoft Foundry agents gained A2A Endpoints and an A2A Tool.
- Foundry introduced a Dev Pack for faster project startup with a single command.
- Microsoft outlined building multimodal applications with OpenAI models in Foundry.
- Playwright Workspaces Remote MCP Server was announced for agentic browser automation.

- Azure Databricks guidance covered what to do when hitting capacity limits.
- Foundry guidance examined why agents can find the right schema but still ignore it.
- Microsoft explored practical local AI for enterprise architects using workload placement.
- New posts examined agent-data patterns, AI guardrail breakage, and operational risks.

- Terraform released v1.16.3.
