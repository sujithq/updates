# Weekly Digest: November 02 – November 09, 2026

## Executive summary

This week was led by a strong push around AI agents, developer productivity, and operational visibility across GitHub, Microsoft Foundry, and Azure. GitHub expanded Copilot into more surfaces and metrics, while Microsoft Foundry added new model, agent, and local/on-device capabilities that matter for enterprise AI delivery. On Azure, networking, storage, recovery, and Kubernetes announcements focused on practical platform maturity, with Application Gateway for Containers and Azure Route Server standing out. Security guidance was also prominent, especially around secret exposure, active exploit mitigation, and reducing on-premises risk.

## GitHub

GitHub’s updates centered on Copilot expansion, better measurement of usage and impact, and improvements to review, repository, and platform infrastructure. The net effect is a more agentic, observable, and enterprise-ready developer experience.

- Copilot code review added API management and review overview updates.
- Copilot impact dashboard now includes chat and VS Code agent usage.
- GitHub published a developer guide to agentic engineering beyond code generation.
- GitHub Copilot weekly releases continued shipping incremental improvements.
- `@GitHub` in Slack and Teams reached general availability.
- Usage metrics API added code review details and addressed rate reporting.
- Usage metrics API now flags telemetry and version gaps.
- GitHub introduced a new pull request overview page in public preview.
- GitHub Copilot became available in Xcode’s coding assistant.
- GitHub detailed its new Git storage architecture and updated CodeQL 2.27.4 accuracy and metadata.

## Ecosystem
