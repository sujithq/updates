# Weekly Digest: Microsoft Azure, GitHub, and Developer Ecosystem  
**Period: July 27 – August 03, 2026**

## Executive summary

This week’s announcements centered on three big themes: tighter AI governance, faster developer workflows, and continued platform expansion across Azure infrastructure and Kubernetes. GitHub pushed forward on Copilot and pull request ergonomics while also tightening supply chain and npm security, and Microsoft’s broader AI stack added new transcription, model availability, pricing updates, and red teaming capabilities. On Azure, notable changes included the AI Gateway preview in API Management, Terraform AzureRM 5.0 GA, new Azure region availability in India South Central, and a steady stream of Azure Updates spanning networking, security, containers, and data services. Cost control and governance also stood out, with multiple announcements around savings plans, Copilot spend management, policy exemptions, and log retention at scale.

## Copilot & Agents

This week’s Copilot news focused on Microsoft 365 Copilot feature updates and improved control over how grounded web content is used. The emphasis was on giving organizations more control while continuing to expand Copilot capabilities.

- Microsoft 365 Copilot received its July 2026 feature roundup.
- Domain Exclusion adds more control over web grounding in Microsoft 365 Copilot.

## GitHub

GitHub’s week combined Copilot improvements, stacked pull request workflows, and stronger security controls across npm and Actions. For engineering teams, the biggest practical changes were around review automation, model governance, dependency management, and more efficient code collaboration.

- GitHub highlighted supply chain defense improvements for npm and GitHub Actions.
