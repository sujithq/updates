# Weekly Digest: September 21–28, 2026

## Executive summary

This week’s announcements centered on three big themes: more capable AI agent platforms, faster developer workflows, and stronger platform security and governance. GitHub and Microsoft Foundry both pushed agentic development forward with updates to Copilot, hosted agents, voice agents, routines, memory, tracing, and browser automation. On the Azure side, container and app platform news was especially strong, with multiple Azure Container Apps and AKS enhancements, while Azure Updates carried several important retirement notices that developers should plan for now. Security also stood out, with Microsoft detailing active cloud attack tradecraft and new identity protections such as proof-of-presence requirements for high-impact GitHub actions.

## GitHub

GitHub’s news this week focused on Copilot expansion, enterprise controls, platform performance, and stronger security protections. The updates matter most for teams standardizing AI-assisted development while tightening governance across repositories, workflows, and user actions.

- GitHub added an in-product validator for enterprise managed settings.
- Usage metrics API now includes pull request review stages.
- Private saved views for repository issues and the “Relates to” issue relationship reached general availability.
- GitHub announced changes to query results in the GitHub Actions API and UI.
- Agentic autofix now uses Copilot Memory.
- Weekly Copilot releases for September 21 shipped another batch of incremental updates.
- GitHub updated Copilot integrations for Slack and Microsoft Teams.
- Copilot features are being enabled by default for Copilot Business and Enterprise.
- GitHub now requires proof of presence for high-impact actions.
- CodeQL 2.27.1 adds C and C++ query updates plus Kotlin 2.4.20 support.

## Data & AI

This week in Data & AI was dominated by Microsoft Foundry’s rapid evolution into a fuller agent platform, with stronger orchestration, observability, networking, and model options. For builders, the key story is that hosted, context-aware, and long-running agents are becoming easier to deploy and govern.

- DeepSeek-V4.1-Flash is coming to Microsoft Foundry.
- Microsoft introduced voice agents in Foundry.
- Foundry Agent Service added network egress controls for hosted agent connections.
- Insights in Foundry now turns agent traces into action.
- Routines in Microsoft Foundry are now generally available for moving from chatbots to automated agents.
- Microsoft announced the Playwright Workspaces Remote MCP Server for agentic browser automation.
- Claude Opus 5.5 is coming to Microsoft Foundry for long-running coding and knowledge work.
- Microsoft outlined its “IQ’s” approach to building context-aware AI.
- Azure SQL Dev Corner published PostgreSQL-to-SQL field notes for date and time handling.
- Analytics on Azure shared a complete guide to Azure Databricks cost optimization.

## Security

Security coverage this week mixed threat intelligence with platform modernization for the agentic era. The strongest signals for practitioners are the continued abuse of cloud identities and the need for improved SOC workflows and phishing-resistant controls.

- Microsoft detailed Storm-3168’s agentic-driven cloud attacks using compromised service principals.
- Microsoft tracked Storm-2570’s consistent ransomware-related tradecraft across deployments.
- Microsoft published its monthly “What’s new in Microsoft Security” roundup for September 2026.
- Microsoft Defender outlined how the SOC is being reimagined for the agentic era.
- Microsoft analyzed EvilTokens and the root causes of device code phishing.

## Azure Updates

Azure Updates this week included several important retirements and upgrade deadlines, along with a handful of preview and GA releases. The most urgent takeaway is lifecycle planning: teams should start preparing now for upcoming end of support across PowerShell, .NET, and Node.js.

- Azure HorizonDB support for PostgreSQL 18 entered public preview.
- Azure Communication Services standalone services will retire on September 30, 2028.
- Instant Access for VM restore points is now generally available.
- Support for PowerShell 7.4 ends on November 10, 2026.
- Support for .NET 8 and .NET 9 ends on November 10, 2026; Azure advises upgrading to .NET 10.
- Support for Node.js 22 ends on April 30, 2027.
- Flex Nodes for AKS entered public preview.
- Azure Sphere OS version 26.09 is now generally available.
- A guided Copilot experience for building Azure apps in VS Code entered public preview.
- Azure Functions now generally supports PowerShell 7.6.

## Ecosystem

The broader ecosystem updates covered architecture patterns, Oracle-on-Azure expansion, infrastructure tooling, and event-driven development. The common thread is tighter integration across clouds, runtimes, and delivery workflows.

- Azure Architecture showed how multimodal GenAI can automate shop floor instructions.
- Oracle AI Database@Azure expanded with Azure Native Oracle GoldenGate user experience and observability.
- Terraform released v1.17.0-beta2 and v1.16.4.
- Linux & Open Source introduced change-driven programming in Node.js with `@drasi/lib`.
- Let’s do DevOps described a full SDLC in a single skill command.
- Microsoft shared reflections from IBC and where media is headed.
