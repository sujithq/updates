# Weekly Digest: Azure, GitHub, and Developer News  
**Period: July 20 – July 27, 2026**

## Executive summary

This week was defined by rapid platform expansion for AI agents and copilots across Microsoft 365, GitHub, and Microsoft Foundry, with Claude Opus 5 showing up prominently in both productivity and developer workflows. GitHub’s announcements focused on operational maturity for Copilot and agent experiences, including new models, cloud agent integrations, usage visibility, billing controls, and issue automation. On Azure, the biggest themes were enterprise AI architecture, networking and governance for agents, and platform capabilities spanning Logic Apps, edge programmability, DDoS controls, and hybrid deployments. For developers and architects, the signal is clear: model choice, agent tooling, observability, and secure production deployment are becoming first-class concerns across the stack.

## Copilot & Agents

Microsoft 365 Copilot news this week centered on stronger model capabilities and the hard realities of enterprise-scale data access for agents. The highlights show both higher-end AI experiences and the infrastructure needed to operationalize them securely inside large organizations.

- Anthropic Claude Opus 5 is now available in Microsoft 365 Copilot.
- Microsoft shared how it built an enterprise-scale Microsoft 365 Copilot connector spanning 1 million documents and 300+ agents.

## GitHub

GitHub’s updates emphasized Copilot platform breadth, agent automation, and tighter management controls for enterprise adoption. The biggest developer takeaways are more model options, more automation in day-to-day workflows, and improved visibility into usage, cost, and governance.

- Claude Opus 5 is now available in GitHub Copilot.
- Gemini 3.6 Flash is now available in GitHub Copilot.
- Copilot cloud agent for Linear is now generally available.
- GitHub Mobile can now use Copilot cloud agent to help fix failing Actions checks.
- GitHub MCP Server now supports the next MCP specification.
- Agent automation controls in GitHub Issues entered public preview.
- Multi-select fields for Projects and Issues entered public preview.
- GitHub added a new Copilot usage metrics impact dashboard.
- AI credit pools for cost centers are now available in the billing UI.
- GitHub detailed Dependabot’s new cooldown approach before issuing version updates.

## Data & AI

Azure’s Data & AI announcements were heavily focused on production agent design: model availability, memory, grounding, networking, tool use, and enterprise implementation patterns. This was also a strong week for multimodal AI, multilingual speech, and practical SQL and Cosmos DB improvements for builders.

- Claude Opus 5 is available today in Microsoft Foundry.
- Microsoft introduced MAI-Image-2.5 Pro and MAI-Voice-2 Flash in Microsoft Foundry.
- Real-time transcription in Microsoft Foundry now goes multilingual.
- Post-Stream Refinement is now generally available in Microsoft Foundry.
- Native Agent Memory for Microsoft Agent Framework is now powered by Azure Cosmos DB.
- Azure Cosmos DB vNext emulator was introduced for AI agent development.
- Microsoft published guidance on grounding Copilot Studio agents with Azure AI Search and Foundry IQ.
- New best practices were shared for Microsoft Foundry Standard Agents with BYOVNet.
- Microsoft outlined how to build agents that act on your behalf with Toolboxes in Foundry.
- Guidance was published on choosing between Copilot Studio and Microsoft Foundry for enterprise AI agents.

- New guidance explains how to test agent experience changes without shipping them.
- July patches were released for Azure DevOps Server.

Azure platform updates centered on integration architecture, hybrid deployment patterns, and governance for MCP-enabled APIs and Logic Apps. The standout stories were large-scale live migration, built-in knowledge in Logic Apps, and deployment flexibility across self-managed and OpenShift environments.

- Microsoft detailed a live-load migration of 60,000 apps.

- Azure Local expanded SAN capabilities with iSCSI support.

## Azure Infrastructure

Infrastructure announcements focused on network security, edge programmability, and HPC scenarios tied to AI and electronic design automation. The most notable updates were the new DDoS custom policy preview and Azure Front Door edge actions.

- Azure DDoS Protection custom policy entered public preview.
- Azure Front Door edge actions were introduced to bring secure programmable logic to the edge.
- Microsoft connected Discovery App to Azure HPC with Azure NetApp Files and CycleCloud.
- Microsoft positioned Discovery as where HPC meets agentic AI for the next era of EDA.

## Security

Security coverage this week balanced strategic threat intelligence with practical incident response. The updates matter most to defenders, security architects, and organizations looking to improve resilience against modern email threats and cyber incidents.

- Microsoft published Q2 2026 email threat landscape trends and insights.

## Governance & Operations

Governance and operations updates highlighted policy enforcement for Kubernetes, observability for AI agents, and migration automation with GitHub Copilot. The common thread is operational control as AI and cloud-native systems become more complex.

- Microsoft published guidance on automating Oracle-to-SQL migration using the SSMA Console Skill in GitHub Copilot.

- Azure DDoS Protection custom policy entered public preview.
