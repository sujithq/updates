# Weekly Digest: October 19–26, 2026

## Executive summary

This week’s announcements centered on three big themes: enterprise AI operationalization, sovereign and controlled-cloud deployment options, and stronger observability/security across Azure and GitHub. Microsoft pushed AI platform maturity forward with multiple Azure AI Foundry updates, including Decisions API general availability, fine-tuning expansion, new hosted agent patterns, and additional model availability. On the platform side, Azure emphasized sovereign infrastructure, Azure Local, confidential computing, and operational tooling for containers, messaging, and observability. GitHub and developer tooling news focused on Copilot governance and integration, enterprise controls for GitHub Apps, and practical productivity improvements across VS Code, Visual Studio, .NET, and Azure DevOps.

## GitHub

GitHub’s updates this week were largely about enterprise administration, Copilot management, and expanding monitoring and usage visibility. For teams running GitHub at scale, the biggest changes improve governance, app deployment, and telemetry for both humans and agents.

- Usage metrics API now includes usage from tools like OpenCode.
- Usage metrics API adds visibility for custom skills, agents, and MCP servers.
- Global default for Copilot features is now generally available.
- Enterprise installations for GitHub Apps reached general availability.
- Public monitoring added triage, validity, API access, and webhooks.
- Public monitoring is now available with data residency support.
- GitHub Copilot in Teams can turn notifications into code workflows.
- GitHub Copilot in Visual Studio received its September update.
- Meta API endpoints were updated for Actions blob storage.
- GitHub published guidance on continuing a Copilot app session in VS Code.

## Data & AI

Azure’s Data & AI story this week showed a clear shift from experimentation to production-grade AI systems, especially in Foundry. Key announcements covered model access, fine-tuning, agent patterns, decisioning, RAG maintenance, and lower-friction data platform operations.

- Foundry added new models including Meta Muse Spark Open, NVIDIA Nemotron 3.5 Super VL, and Reflection Beam.

- Azure Databricks Serverless private connectivity was simplified with Private Network Gateway.
