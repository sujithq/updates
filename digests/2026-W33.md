# Weekly Digest: Azure, GitHub, and Developer News  
**Period: August 03 – August 10, 2026**

## Executive summary

This week’s announcements centered on three major themes: tighter AI agent governance, stronger platform security, and more operational control for enterprise developers. Microsoft and GitHub both shipped meaningful updates around Copilot, agent workflows, review controls, usage telemetry, and secure enterprise policy management. On Azure, App Service, Azure Arc, networking, and Azure Updates brought several practical platform enhancements, while Data & AI coverage focused heavily on Foundry models, optimization, fine-tuning, and multi-agent development. Security news was also substantial, with new Sentinel capabilities, stronger Zero Trust for AI guidance, and fresh threat research relevant to defenders and platform teams.

## Copilot & Agents

This week’s Copilot and agent news focused on governance and adoption. The biggest theme was improving control over Microsoft 365 Copilot web grounding while continuing to push practical guidance for enterprise rollout.

- Microsoft 365 Copilot added Domain Exclusion to give organizations more control over web grounding.
- A second Microsoft 365 Copilot post expanded on Domain Exclusion and its governance implications.
- Agent 365 published its July 2026 roundup of new capabilities and updates.
- Microsoft highlighted a partner story on moving from AI curiosity to Copilot adoption in 30 days.

## GitHub

GitHub’s updates were especially strong for enterprise admins, platform teams, and organizations scaling Copilot. Key changes covered app governance, review workflows, metrics, issue management, and secure policy controls.

- Enterprises can now install third-party GitHub Apps.
- GitHub Copilot weekly releases for August 3 delivered the latest incremental product changes.
- Copilot impact dashboard now includes a return on investment section.
- Copilot code review effort levels reached general availability.
- Copilot usage metrics API now includes agent app activity.
- MCP allowlists were added to enterprise managed settings.
- Organizations can now set pull request limits at the org level.
- “Relates to” issue relationships entered public preview, and multi-select fields became generally available.
- Secret scanning coverage received updates.
- GitHub shared guidance on turning one giant AI-generated pull request into a reviewable stack.

## Data & AI

- Microsoft Foundry introduced a new model wave.

- Foundry coverage explored reinforcement fine-tuning via hill-climbing after distillation.
