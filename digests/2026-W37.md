# Weekly Digest: August 31 – September 07, 2026

## Executive summary

This week was dominated by rapid model expansion across Microsoft Copilot, GitHub Copilot, and Microsoft Foundry, with GPT-6 Astra, Claude Fable 5.1, Gemini 3.8 Flash, and new MAI image and transcription models broadening enterprise AI choices. GitHub paired those model updates with practical platform changes around Actions, CodeQL, trusted publishing, privacy-safe analytics, and multi-agent workflows. On Azure, the biggest signals were around infrastructure maturity and operations: Azure Virtual Desktop Hybrid reached general availability, Azure Firewall added key capabilities, Azure API Management advanced AI gateway and asynchronous API patterns, and AKS/Kubernetes updates focused on scaling, storage, and security. Security and governance also stood out, with multiple incident-focused advisories and expanded low-cost logging and policy enforcement options for enterprise operations.

## Copilot & Agents

Microsoft’s Copilot portfolio added major new foundation model options and continued its steady monthly feature cadence. The key theme is customer choice: more models, broader assistant capabilities, and faster access to frontier AI inside Microsoft’s productivity stack.

- OpenAI GPT-6 Astra is now available in Microsoft Copilot.
- Anthropic Claude Fable 5.1 is now available in Microsoft Copilot.
- Microsoft published its August 2026 roundup of new Copilot features and updates.
