# Weekly Digest: Microsoft Azure, GitHub, and Developer News  
**Period: September 07 – September 14, 2026**

## Executive summary

This week’s news centered on AI-assisted development, production-ready platform enhancements, and stronger security controls across GitHub and Azure. GitHub continued to expand Copilot, code review, Actions, and supply-chain capabilities, while Microsoft’s AI platform updates focused on multimodal apps, enterprise voice patterns, evaluation, and guardrails. On Azure infrastructure and platform, several notable general availability milestones landed, including Azure Copilot’s Troubleshooting Agent, user-bound SAS for Storage, ephemeral OS disk full caching, and Dell Managed PowerScale for Azure. Kubernetes and AKS updates also stood out, with Kubernetes v1.37 feature progress and new AKS scheduler profile flexibility for workload-aware operations.

## GitHub

GitHub’s biggest themes were Copilot workflow improvements, repository and API enhancements, and tighter operational/security controls for Actions, npm, and CodeQL. The updates matter most for teams standardizing AI-assisted development while improving governance and visibility.

- Copilot usage metrics now include VS Code Agents, giving teams broader measurement of AI-assisted development activity.
- Copilot code review received auto-resolution and analysis updates to streamline review workflows.
- The weekly Copilot release roundup for September 7 collected the latest shipping changes across the product.
- GitHub published a beginner-focused Copilot app walkthrough covering diff, terminal, and browser usage.
- The repository pull requests page entered public preview with a refreshed experience.
- AI Scan for pull request APIs entered public preview, extending AI-powered analysis into PR integrations.
- GitHub Actions introduced `cache-mode` to control cache access behavior more precisely.
- MAI-Code-1-Flash was deprecated, signaling model lifecycle changes developers need to plan for.
- Xcode 27 runner images now run on macOS 27 for Apple platform build pipelines.
- npm extended recovery-code security holds to all accounts, strengthening account recovery protections.
- CodeQL 2.27.0 added Linux ARM64 support, expanding analysis coverage for modern build targets.
- GitHub’s August 2026 availability report provided transparency into platform reliability and incidents.
- GitHub showcased “marketing ops as code,” illustrating broader GitHub automation patterns beyond software delivery.
